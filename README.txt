FLOWKEM DYNAMIC LANDING PAGE
=============================

This is a real responsive HTML/CSS/JS landing page, not a single flattened poster.

Open index.html in a browser.

Editable elements:
- Logo: assets/flowkem-logo.svg
- Background: assets/skyline-bg.jpg
- Product layer: assets/products.png
- Typography/layout: style.css
- Mouse/parallax interaction: script.js

The page is locked to one viewport and intentionally has no scrolling.
